Your Calendar Hookup

Subscribe once with this private link and every new booking shows up in your calendar automatically. Works with Google Calendar, Apple Calendar, and Outlook.

How to subscribe (one time)
  1. Google Calendar: On a computer, go to calendar.google.com → Settings (gear) → Add calendar → From URL → paste the link → Add calendar.
  2. Apple Calendar (iPhone/Mac): Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → paste the link.
  3. Outlook: Calendar → Add calendar → Subscribe from web → paste the link.
